Rating source

Unlocks every source except IMDb, which is read from a local copy of IMDb’s own ratings file and needs no key. Free tier: 1000 requests a day. Stored in plaintext in the plugin configuration file (server file permissions apply).
Governs both files the IMDb source needs: the ratings list (~9 MB) and, for season scores, the episode list (~55 MB). IMDb regenerates them once a day, so nothing below daily helps. “Never” stops re-downloading but still fetches each file once if it is not there yet.

Item levels

Which kinds of item to write ratings for. This applies to every enabled library. If a library’s source has no score at one of these levels, those items are cleared rather than left alone — the field shows the configured source or nothing.

Libraries

Select the libraries this plugin is enabled for. Optionally pick a rating source per library; libraries left on “(Use default)” use the default source above.
