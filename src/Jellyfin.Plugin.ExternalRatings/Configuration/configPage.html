Dry run is enabled — the plugin computes ratings but does not write to your library.

Provider

Stored in plaintext in the plugin configuration file (server file permissions apply).
IMDb regenerates the ratings file once a day, so there is nothing to gain below 24. The download is roughly 9 MB and needs no key or quota. 0 disables refreshing.

Item levels

Which kinds of item to write ratings for. Levels the selected provider cannot supply are shown disabled. Enabling episodes can multiply the number of processed items by a hundred in a TV library.
